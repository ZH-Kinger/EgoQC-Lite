# QC 模型数据计划

目标不是让一个模型读取数百 TB 原始数据，而是构造“规则全量筛查 + 教师模型难例标注 +
小模型高吞吐推理 + 低置信人工复检”的闭环。模型的 99% 指标必须按错误类型、供应商和场景
报告；不能用正常样本占多数的 overall accuracy 代替。

## 数据分层与用途

| 层 | 建议起步量 | 稳定生产量 | 用途 | 能否作为最终评测真值 |
|---|---:|---:|---|---|
| 无标签原始视频 | 每来源 100–500 小时 | 1,000–10,000+ 小时 | 视频表征预训练、覆盖人物/场景/相机长尾 | 否 |
| 规则召回候选 clip | 20,000–50,000 条 | 100,000+ 条持续滚动 | 给教师模型打 soft label，训练学生模型 | 否 |
| 随机正常与困难负例 | 候选集的 20%–40% | 每个来源/任务/场景持续补充 | 控制误杀、发现规则未召回的新错误 | 否，除非人工复核 |
| 人工 Gold train | 每类 500 正例 + 500 负例 | 每类 1,000–2,000 正例及匹配负例 | 修正教师偏差、监督训练、难例回流 | 是 |
| Gold validation | 每类 200 正例 + 600 负例 | 每类 500 正例 + 1,500 负例 | 阈值搜索、概率校准、选择 abstain 区间 | 是，但不能用于最终报告 |
| 锁定 Gold test | 每类至少 400 正例 + 2,000 负例 | 高风险类 1,000–2,000 正例 + 5,000 负例 | 供应商隔离的最终验收与置信区间 | 是 |
| 合成异常 | 5,000 个干净 clip，每个 5–20 个变体 | 按失败类型动态补充 | 时间偏移、相机参数、左右手、抖动、冻结等可控监督 | 只用于训练/单元测试 |

4–8 秒 clip 按平均 6 秒估算：20,000 条约 33 小时视频，100,000 条约 167 小时。
因此教师 API 只处理候选 clip，其输入量通常远小于全量视频。

## 为什么需要这些层

1. **无标签视频**解决覆盖度，不承担质量真值。公开数据可用于视频表征预训练，即使没有 MANO；
   供应商数据用于适配真实相机、动作和场景分布。
2. **规则召回 clip**把昂贵模型调用集中在抖动、遮挡、重建漂移等疑难位置。schema、FPS、
   timestamp、SO(3) 等仍由代码全量判断。
3. **随机正常负例**防止模型只看异常候选而形成“进队列即有错”的偏差，也能估计规则漏召回。
4. **人工 Gold**是唯一能够校准阈值和证明准确率的数据。教师模型标签只能作为 Silver，不能
   自己给自己做评测。
5. **合成异常**精确控制偏移量和错误类型，适合补足真实数据中很少出现但后果严重的错误。
6. **供应商/人物/场景隔离测试**防止相邻 clip、同一个人或同一背景泄漏导致虚高结果。

## 99% 指标的正确口径

- 对自动拒收，优先约束 **precision ≥ 99% 且 95% 置信下界 ≥ 99%**，避免大量误杀好数据。
- 对严重错误发现，另报 recall；precision 很高但 recall 很低也不能称为整体 99%。
- 小样本全对不等于 99%。在零误判的理想情况下，也约需 400 个预测正例，95% Wilson 下界
  才接近 99%；一旦有误判，需要更大的锁定测试集。
- 生产系统通过三路决策达到高可靠性：高置信通过、高置信拒收、中间区域人工复检。模型无需
  强行判断所有样本。

## 每条 clip 至少需要的字段

- `source_dataset/source_revision/supplier_id`；
- `person_id` 或 `operator_id`、`collection_session_id`；
- `scene_id/camera_id/task_id`；
- 原 MP4 URI、聚合视频绝对 `clip_start_s/clip_end_s`；
- 规则事件、模型版本、prompt 版本和输出置信度；
- 人工 reviewer、复核/仲裁信息和标签版本；
- 许可证或内部授权编号；
- 若存在：内外参、MANO、相机轨迹、遮挡标签和任务/子任务文本。

缺少人物或 session 身份时，数据仍能训练，但不能安全地构造无泄漏评测集；缺少授权信息时，
只能进入 technical candidate，不能进入正式训练视图。

## 第一轮实际建议

先从 3 个来源各抽 300–500 个 episode，运行规则扫描并自动生成约 3,000–10,000 个候选 clip。
教师模型对候选做广义审查，人工复核其中 2,000–4,000 条，并额外人工检查每个来源至少 500 条
随机正常 clip。第一轮的目标是校准 taxonomy、发现未知错误和测教师一致性，不宣称 99%。

taxonomy 稳定后再扩至 20,000–50,000 个教师标签、每类至少 500 个 Gold 正例，并冻结按
供应商/人物/session 隔离的 validation/test。之后每周只标新增分布、模型分歧和低置信样本，
而不是重复扫描历史全量数据。
